# Security

## Reporting a vulnerability

Report suspected vulnerabilities privately to the repository owner. Include the affected version or commit, reproduction steps, expected impact, and any safe supporting evidence. Do not publish credentials, private identifiers, transcripts, or exploit details in a public issue.

## Deployment guidance

Hermes Live is self-hosted. Keep the local control API bound to loopback, use explicit owner identity settings, protect provider credentials, and review transcript retention and notification destinations before enabling optional integrations.
